Before the room enters

Exactly where installation happens
  1. Install Node 24 before launching the console.
  2. Download and unzip the kit. From its folder, launch the console:
node server.mjs --open

Keep that terminal open. In a second terminal, from the same kit folder:

node wallet-setup.mjs

Inside the console, step 01 checks the runtime. Step 02 saves the wallet and strategy. Step 03 Install agent runs npm ci. Step 04 Run once starts the actual recipe process.

QR links and operator funding sequence
https://holonym-foundation.github.io/basecamp-builder-lab/deploy.html
https://holonym-foundation.github.io/basecamp-builder-lab/register.html
  1. Build QR first: install the kit and create the wallet.
  2. Builders copy their Sui address into Strategy. Funding asks for email and includes that saved address. A direct Funding QR scan asks for both.
  3. On the private operator screen, load controls and prepare registration. No attendee codes.
  4. When ready, open the 15-minute window. Keep its exact cutoff visible on the operator screen.
  5. After cutoff, export campaign.json and responses.csv. The payout agent creates an offline plan with approved amount, total, source address and sender reserve.
  6. Review email/address pairs, selected recipients and total. Execute using the dedicated aex funding session and one durable ledger. Stop on unresolved results; verify each transfer receipt.

The operator key is a host credential, never a participant requirement or a projected QR. The form does not send funds.
