Hunt: research a Sui build in one prompt

Use any chat agent that can browse. You get three official sources and a next step for each, then you check that every link is real.

The prompt
Find three useful resources for someone building an agent on Sui. Use official documentation. For each, give the page title, a working URL, a one-sentence summary and one practical next step. Do not connect a wallet, call an RPC or send transactions. If you cannot browse, say so and work only from the source excerpts I supply.
Steps
  1. Open a chat agent with web access (Claude, ChatGPT, Gemini or similar).
  2. Paste the prompt and send it.
  3. Open every link it returns. Check that the page loads and its heading matches the title the agent gave.
  4. Pick one next step and do it, or note why you can't.
  5. If your agent can't browse, open the three source tabs below, paste a short excerpt from each, and send the prompt again.

The agent's answer is a claim. The links are the evidence. A link that doesn't load, or a title that doesn't match, means the answer needs work.
